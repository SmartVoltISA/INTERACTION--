# INTERACTION--

## RU
Исследование взаимодействия как процесса взаимного изменения состояния, энергии, информации и отношений между системами. Изучаются механизм, направление, масштаб, результат и обратная связь.

## EN
Research of interaction as mutual change in state, energy, information and relations between systems. Focus: mechanism, direction, scale, outcome and feedback.

## 中文
研究相互作用作为系统之间状态、能量、信息和关系相互变化的过程。重点研究机制、方向、尺度、结果和反馈。

## Foundation
SYSTEM-FOUNDATION → INTERACTION-- → state → transition → result → feedback → verification
